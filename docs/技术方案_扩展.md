# EasyVIEW 扩展技术方案（摄像机管理增强）

> 在基础方案（PyQt6 + LibVLC 实时预览）之上，扩展摄像机管理模块：
> ONVIF 自动发现/配网、PTZ 云台、本地录像与回放、多厂商 RTSP 模板、凭据加密存储。
> 本文承接 `docs/技术方案.md`，聚焦新增模块的设计与实现要点。

---

## 1. 凭据加密存储（密钥不落明文）

**问题**：摄像机账号密码明文入库存在泄露风险。

**方案**（`core/crypto.py` — `CredentialVault`）：
- 对称加密用 `cryptography.Fernet`（AES-128 + HMAC）。密文写入 `cameras.password`。
- **主密钥不落明文文件**：优先存入 OS 凭据库（keyring 后端）：
  - Windows → Credential Manager
  - macOS → Keychain
  - Linux → Secret Service（GNOME/KDE 钥匙环）
- 仅当无可用凭据后端时，回退为本地密钥文件 `~/.easyview/vault.key`（权限 `chmod 600`），并在日志告警。
- 密钥以**单例**加载，避免重复读写凭据库。

**数据流**：`Camera.password` 在内存中始终为明文；入库时 `add_camera/update_camera` 调用 `vault.encrypt`；出库时 `list_cameras/get_camera` 调用 `vault.decrypt`。预览/PTZ/测试用的都是内存明文，无感知。

## 2. ONVIF 自动发现与配网（WS-Discovery）

**实现**（`core/onvif_discovery.py`）：
- 手写 WS-Discovery 多播探测（**零额外依赖**）：向 `239.255.255.250:3702` 发送 SOAP `Probe`（`Types=dn:NetworkVideoTransmitter`）。
- 加入组播组并监听单播回包，解析 `ProbeMatch` 中的 `EndpointReference`、`XAddrs`、`Scopes`（含 `manufacturer`/`model`）。
- 按 `endpoint` 去重，返回设备清单。

**配网**（`ui/discovery_dialog.py`）：
- 发现列表展示「厂商 型号 @ IP」；选中后可填账号密码点「获取流地址」，通过 ONVIF `GetStreamUri` 拉取**权威 RTSP**（含鉴权），写入 `cameras.stream_uri`，预览时优先使用。
- 「添加所选」自动匹配 `vendor`（见第 3 节）。

**ONVIF 客户端**（`core/onvif_device.py` — `OnvifDevice`，基于 `onvif-zeep`）：
- `device_info()` 取厂商/型号/固件；`vendor_key()` 映射到 RTSP 模板。
- `stream_uri()` 取主码流 RTSP。
- 所有调用异常兜底，设备不支持某项能力时安全降级。

## 3. 多厂商 RTSP 模板与自动匹配

**实现**（`core/rtsp_templates.py`）：
- `TEMPLATES` 按厂商定义路径构造 lambda：
  - 海康：`/Streaming/Channels/{ch}{01|02}`
  - 大华/乐橙：`/cam/realmonitor?channel={ch}&subtype={0|1}`
  - 宇视：`/media/video{ch}?stream={main|sub}`（固件差异大，以 ONVIF 为准）
  - 通用 onvif：兜底 + 优先用 `GetStreamUri`
- `match_vendor(manufacturer)` 将 ONVIF 返回的厂商名映射到模板 key（`ONVIF_MANUFACTURERS`）。
- `Camera.rtsp_url()` 统一入口：有 `stream_uri` 优先返回，否则按模板构造；密码做 URL 编码。

## 4. PTZ 云台控制

**实现**（`core/onvif_device.py` + `ui/ptz_panel.py`）：
- **绝对转动** `move_absolute(pan,tilt,zoom)`：基于 `GetStatus` 当前位姿叠加步长。
- **相对转动** `move_relative(pan,tilt,zoom)`：以增量 `Translation` 移动。
- **连续转动** `move_continuous(vx,vy,vz)`：速度分量 [-1,1]，`timeout` 秒后自动 `Stop`（独立 `Timer`）。
- **预置位**：`get_presets / goto_preset / set_preset / remove_preset`；面板列表双击跳转。
- **巡航**：ONVIF 无统一巡航标准，采用**预置位轮巡**——`start_cruise(tokens, interval)` 用 `Timer` 循环 `GotoPreset`，`stop_cruise` 取消。
- 面板提供方向键盘（8 向 + 变倍 ±）、模式切换、步长、预置位增删/跳转、巡航启停与间隔。

## 5. 本地录像：启停 / 分段 / 回放

**实现**（`core/recorder.py` + `core/playback.py`）：
- **独立录制**：每路录像用独立 `MediaPlayer`（独立 RTSP 连接），`sout=#std{access=file,mux=mp4,dst=path}` 仅写文件、不显示，避免与预览互扰。
- **分段存储**：`segment_seconds>0` 时，定时 `stop` 当前段并开新段，每段一个 mp4；每段结束经 `on_segment` 回调写入 `recordings` 表（`camera_id,path,start_time,end_time,size`）。`0` 为不分段。
- **回放检索**：`search_recordings(camera_id,date)` 查库返回片段；面板双击即在该预览窗格 `play_file(path)`（file:// 播放）。
- `RecorderManager` 管理多路并发启停；退出时 `stop_all`。

> 注：部分摄像机限制同时 RTSP 连接数，多路录像建议走子码流（`stream_type=sub`）。

## 7. 依赖

```
PyQt6, python-vlc          # 基础
cryptography, keyring      # 凭据加密（密钥存 OS 凭据库）
onvif-zeep                 # ONVIF 设备管理与 PTZ
```

## 8. 落地与使用

1. `pip install -r requirements.txt`，确保已装 VLC。
2. 工具栏「发现设备」→ 选设备 → 填账号密码 →「获取流地址」→「添加所选」。
3. 双击列表预览；选中某路后点「云台」调云台，「录像」启停并回放。
4. 手动添加时在对话框内也可点「从 ONVIF 发现导入」自动填参。

## 9. 已知约束与后续

- `onvif-zeep` 首次需联网拉 WSDL；离线环境可预置 WSDL 目录（`wsdl_dir`）。
- 宇视等小众厂商 RTSP 格式随固件变化，建议一律以 ONVIF `GetStreamUri` 为准。
- 巡航为预置位轮巡实现；如需设备原生巡航轨迹，可接入厂商 SDK。
- 凭据主密钥回退文件仅在无 keyring 后端时使用；生产环境请配置后端。
