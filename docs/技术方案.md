# EasyVIEW 技术方案（轻量级视频监控预览客户端）

> 目标：开发一款功能精简、聚焦**视频实时预览**的桌面客户端，参照海康威视 IVMS-4200 的布局风格，支持 Windows / Linux。
> 本文给出技术选型、整体架构、模块划分、核心实现要点、目录结构与关键代码，可直接落地开发。

---

## 1. 技术选型

### 1.1 候选方案对比

| 维度 | 方案 A：PyQt6 + LibVLC（**推荐**） | 方案 B：Electron + LibVLCSharp/Avalonia | 方案 C：.NET MAUI + LibVLCSharp |
|---|---|---|---|
| UI 框架 | Qt 6（PyQt6）原生控件 | Web（Chromium）+ React | XAML 原生 |
| 视频解码 | LibVLC（直接 RTSP 硬解，无转码） | LibVLC | LibVLC |
| 跨平台 | Windows / Linux（同一套代码） | Windows / Linux / macOS | Windows / Linux / macOS / 移动端 |
| 开发语言 | Python 3.10+ | TypeScript | C# |
| 打包体积 | 中等（PyInstaller 打包 VLC） | 较大（Chromium 内核） | 中等 |
| 上手成本 | 低（代码即文档，参考实现见本工程） | 中（需处理原生模块与 Electron 主进程通信） | 中（需 .NET SDK） |
| 实时预览性能 | 优（LibVLC 硬解） | 优 | 优 |

### 1.2 最终选型与理由

**主推方案 A：Python 3 + PyQt6 + LibVLC（python-vlc 封装）。**

核心判断依据：

1. **视频解码是成败关键**。监控摄像机输出的是 RTSP（H.264/H.265）码流。最稳妥的做法是**直接用 LibVLC 拉流并硬解渲染到窗口**，而不是把 RTSP 转码成 HLS/WebRTC 再喂给浏览器——后者在多路上会消耗大量 CPU 且增加延迟。LibVLC 是 VideoLAN 官方维护、跨平台、支持硬件加速（DXVA2 / VAAPI / VDPAU）的成熟方案。
2. **PyQt6 提供原生跨平台控件**，左侧树形列表 + 右侧网格的布局用 `QListWidget` + `QGridLayout` 即可精确还原 IVMS-4200 观感，且 Windows/Linux 一套代码。
3. **参考实现可直接运行**：本工程已给出完整可运行代码，降低落地门槛。

> 若团队更熟悉 Web 技术栈，可改选方案 B（Electron 内嵌 LibVLCSharp 的 Web 绑定，或 Avalonia + LibVLCSharp），架构与模块划分完全通用，仅表现层替换。

### 1.3 视频解码方案（重点）

- 每个预览窗格 = 一个 `vlc.MediaPlayer`，共用一个 `vlc.Instance`。
- 渲染目标：将子 `QFrame.winId()` 句柄交给 VLC（`set_hwnd` on Windows / `set_xwindow` on Linux）。
- 低延迟调优参数：`--rtsp-tcp`（TCP 传输抗丢包）、`--network-caching=300`、`--avcodec-hw=any`（硬件解码）、`--drop-late-frames --skip-frames`（卡顿时丢帧保流畅）。
- **不做转码**：VLC 直接解码输出到显存，CPU 占用远低于 FFmpeg→浏览器方案。

## 2. 整体架构设计

采用**分层架构**，表现层、业务逻辑层、媒体层、数据层解耦：

```
┌──────────────────────────────────────────────────────────────┐
│  表现层 (Presentation)            PyQt6 Widgets                │
│   MainWindow · CameraListPanel · VideoGrid · PreviewWidget ·   │
│   CameraDialog · ToolBar                                       │
└───────────────┬───────────────────────────┬──────────────────┘
                │ 调用                        │ 信号/事件
┌───────────────▼──────────────┐  ┌──────────▼──────────────────┐
│  业务逻辑层 (Business)         │  │  媒体层 (Media)             │
│   CameraManager: CRUD/测试     │  │  LibVLC Instance + Player    │
│   LayoutManager: 布局策略       │  │  RTSP 拉流 / 硬解 / 渲染      │
│   StreamManager: RTSP 地址构造  │  │  (python-vlc)                │
└───────────────┬──────────────┘  └──────────────────────────────┘
                │
┌───────────────▼──────────────┐
│  数据层 (Data)                 │
│  SQLite: cameras 表（本地配置） │
└───────────────────────────────┘
```

数据流向（以「添加摄像机并预览」为例）：
1. 用户在 `CameraDialog` 填写 IP/端口/账号/密码 → `CameraManager.add_camera()` 写入 SQLite。
2. 左侧列表刷新；用户双击列表项 → 发出 `playRequested`。
3. `MainWindow` 调用 `VideoGrid.play_camera(camera)` → `PreviewWidget.start()`。
4. `PreviewWidget` 经 `Camera.rtsp_url()` 构造 RTSP 地址，交给 `vlc.MediaPlayer.play()` 渲染到窗格。

## 5. 核心功能实现要点

### 5.1 摄像机管理
- **添加/编辑/删除**：表单 → `CameraManager` → SQLite。密码明文存储于本地库（单机工具可接受；如需安全可改为系统凭据托管或加密存储）。
- **连接测试（两阶段）**：① `socket.create_connection` 测 TCP 端口可达（秒级失败）；② 用 VLC 试拉 RTSP 流，监听 `MediaPlayerPlaying` / `EncounteredError` 事件，超时返回结果。见 `core/camera.py:test_connection`。
- **RTSP 地址构造**：海康格式 `rtsp://user:pass@ip:port/Streaming/Channels/101`（主码流）/ `102`（子码流）；用户名密码做 URL 编码避免特殊字符鉴权失败。

### 5.2 视频预览
- 预创建 `MAX_CHANNELS`(9) 个 `PreviewWidget`，布局切换时**复用**而非销毁，避免 MediaPlayer 频繁创建。
- 共用一个 `vlc.Instance`，每个窗格一个 `MediaPlayer`；渲染句柄按平台选择 `set_hwnd` / `set_xwindow`。
- 低延迟参数见 `core/config.py:VLC_ARGS`。

### 5.3 画面布局
- 最多 64 路（8×8 监控墙），`core/config.py:MAX_CHANNELS`。
- 按窗口数量自动排版（`ui/layouts.py:auto_layout`）：完美平方数用等分网格，其余优先「1 大(2×2) + N 小」，例如 6 路 = 1 大 + 5 小（3×3 网格）、5 路 = 1 大 + 4 小（2×4）、13 路 = 1 大 + 12 小（4×4）；无合适「1 大」排版时退化为等分。
- 窗格用 `(row, col, row_span, col_span)` 描述，`VideoGrid.apply_layout(rows, cols, tiles)` / `apply_count(n)` 支持跨格大窗。
- 布局切换 = 清空 `QGridLayout` 后重新 `addWidget` 可见窗格，隐藏多余窗格并 `set_camera(None)` 停止其流；收缩时把被隐藏格子的设备迁移到空闲格子。

### 5.4 全屏与双击单画面
两种全屏互不影响：
- **单路全屏**（双击窗格）：`PreviewWidget.doubleClicked` → `VideoGrid.on_double_click` 发出请求，`MainWindow._enter_preview_fullscreen` 让该控件在网格内铺满并隐藏其余窗格，隐藏框架后对主窗口 `showFullScreen()`；再次双击或 `Esc` 还原。
- **视窗全屏**（工具栏「视窗全屏」按钮 / 视图菜单 / `F11`）：`MainWindow._window_fullscreen` 仅隐藏菜单/工具栏/列表/停靠窗并对主窗口 `showFullScreen()`，**保留当前全部窗格**（整墙全屏），不放大单路。
- 两者都直接对现有主窗口 `showFullScreen`，**不把控件 `setParent(None)` 浮出为顶层窗口**——含原生 VLC 子窗口的控件重挂为顶层后，平铺式 Wayland（XWayland）会拒绝其全屏请求。`_chrome_hidden` 保证框架快照只记录一次，窗口全屏与单路全屏可互相切换且退出后正确还原。

### 5.5 跨平台与性能优化
- **跨平台**：PyQt6 + LibVLC 均为原生跨平台；渲染句柄按 `sys.platform` 区分；深色主题用 Fusion 风格统一观感。
- **性能**：
  - 子码流(`102`)用于多画面预览、主码流(`101`)用于单画面/全屏，平衡清晰度与带宽。
  - 硬件解码 + 丢帧策略保证弱网卡顿时不阻塞 UI 线程（VLC 解码在独立线程）。
  - 预览控件池复用，减少对象创建开销。
- **Linux 注意**：若 libvlc 不在标准路径，设置 `PYTHON_VLC_LIB_PATH` 环境变量。

## 6. 关键代码示例（摘录）

**RTSP 地址构造（海康）** —— `core/camera.py`
```python
def rtsp_url(self) -> str:
    stream_code = "01" if self.stream_type == "main" else "02"
    path = f"/Streaming/Channels/{self.channel}{stream_code}"
    user = quote(self.username, safe="")
    pwd = quote(self.password, safe="")
    return f"rtsp://{user}:{pwd}@{self.ip}:{self.port}{path}"
```

**VLC 渲染到窗格** —— `ui/preview_widget.py`
```python
if self.player is None:
    self.player = self.instance.media_player_new()
    win_id = int(self.video_frame.winId())
    if sys.platform.startswith("win"):
        self.player.set_hwnd(win_id)      # Windows
    else:
        self.player.set_xwindow(win_id)   # Linux (X11)
```

**两阶段连接测试** —— `core/camera.py`
```python
with socket.create_connection((cam.ip, cam.port), timeout=timeout): ...   # 阶段一 TCP
# 阶段二：监听 MediaPlayerPlaying / EncounteredError 事件，超时返回
```

## 7. 部署与打包

- **Windows**：`pyinstaller -F -w main.py`，目标机需安装 VLC（或把 VLC 目录随包分发并在代码中指定 `VLC_PLUGIN_PATH`）。
- **Linux**：`pyinstaller -F main.py`；分发确保目标机 `apt install vlc libvlc-dev`。
- 建议将 `data/` 加入 `.gitignore`（含本地摄像机库）。

## 8. 扩展建议（路线图）

1. **ONVIF 自动发现**：集成 `wsdiscovery` + ONVIF 客户端，局域网内自动搜摄像机并填入默认参数。
2. **PTZ 云台控制**：通过 ONVIF/SDK 发送转动/变倍指令，预览窗格叠加控制条。
3. **本地录像**：`vlc.MediaPlayer` 的 `media.add_option("sout=...")` 录制为 MP4，或接摄像机 SDK 拉录像流。
4. **多厂商兼容**：在 `Camera` 增加 `rtsp_template`，适配大华(`/cam/realmonitor?channel=1&subtype=0`)、宇视等。
5. **截图与轮巡**：`player.video_take_snapshot()` 截图；轮巡模式按间隔切换单画面源。
6. **配置加密**：摄像机密码改用系统凭据库（Windows DPAPI / Linux Secret Service）存储。

## 9. 落地步骤（建议）

1. 安装 Python 依赖 + VLC 运行时（见 README）。
2. 运行 `python main.py`，添加一个摄像机（IP/端口/账号/密码，默认 554）。
3. 双击列表项预览；输入窗口数量（如 6 → 1 大 + 5 小）验证自动排版；双击窗格单画面、全屏验证。
4. 按第 8 节逐步补充 ONVIF、PTZ、录像等能力。
